# Incident 2026-10-28: one account fuzzes every endpoint for seven hours

Account `istevens599@6gdfg.zone.id` (user `88e201ae-c353-41cb-bb3c-57344a02ae32`), one Google Cloud IP
(34.145.17.47), 2026-10-28 11:12Z to 18:31Z. Found by the owner the next morning from the alert mail and PostHog.

## What it reached

Nothing of value. Verified 2026-10-29 from the Railway http log (501 requests), `account_mcp_calls`,
`credit_transactions` and Resend:

- Free Auto: 110 chats answered, then 123 × 402 and 2 × 429. The per-user share held. Spend: $0.031 Bedrock.
- Wallet: 14 `debit_wallet` calls with `p_cents` up to 2^31 took its own wallet to −8,589,934,601 cents. No other
  wallet went negative; nothing was credited anywhere.
- Connectors: 232 registered, an SSRF test-suite (metadata addresses, Railway-internal names, nip.io / sslip.io /
  1u.ms / rbndr.us rebinding, NAT64, 6to4, hex/octal/decimal IPs, redirect-to, userinfo tricks). 238 `/v1/mcp/call`
  attempts, 33 `ok`, every one of them to its own public test servers (httpbingo canned JSON, webhook.site). Every
  private target was refused or unreachable. `POST /v1/connectors/probe1/credential` answered `{ok:false,
  error:"not_found"}` with HTTP 200: ownership is checked.
- `send-email` edge function: an open relay (client chose recipient, subject, body). 28 sends, none to a real
  person (Resend).
- 148 forged Lemon Squeezy webhooks: 401. RLS held on users / credit_* / github_installs. Relics paywall: 402.
- It saw no other user's data: users count came back 1 (itself); every connector id it touched was its own.

## Related: the PostHog token leak (found the same day)

Since 2026-10-23 the website's PostHog captured `$current_url` with the OAuth fragment on `/auth/app?client=cli`
(26 events, 13 anonymous persons, 4 accounts: 3 Google, 1 GitHub; no provider refresh tokens; Google access tokens
expire in 1 h; the GitHub `gho_` tokens do not). Also possible on `/auth/reset` and `/auth/confirm` (`?token_hash`).

- Closed in launchpad (branch `team/security`): `before_send` scrubs every URL property; the four auth pages clear
  the address bar the moment they have read it; CLI sign-ins are identified to the account id with `client: cli`.
- Sessions revoked 2026-10-29: 123 refresh tokens and 15 sessions deleted for the 4 accounts (they sign in again).
- PostHog: the 13 persons are personless (memory persistence, `identified_only`), so the persons API cannot delete
  their events (`persons_found: 0`). The events are inert now (every token in them is revoked or expired) and age out
  with the 12-month retention. A support request for a targeted purge is the only faster path.
- GitHub: all user tokens on the OAuth App revoked 2026-10-29 (owner, sudo). Atlarix never uses provider tokens, so nothing breaks.
