# Previous versions (v3 and below)

When Atlarix moves to **v4** and above, all v3.x and earlier entries from the main [CHANGELOG.md](CHANGELOG.md) will be summarized or linked here so the current changelog stays focused on the latest major version.

Until then, the full history remains in [CHANGELOG.md](CHANGELOG.md). After **7 releases** in the current changelog, consider moving the oldest 7 to a separate page (e.g. `changelog-page-2.md`) and linking it here.
