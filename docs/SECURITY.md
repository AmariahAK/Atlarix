# Security Policy

## Supported Versions

We will provide security fixes for the latest version of Atlarix and encourage Atlarix users through auto-updates to use the latest version of the app.

## Reporting a Vulnerability

Email **security@atlarix.dev**. We acknowledge within 48 hours.

You can also file privately via [GitHub's report-a-vulnerability form](https://github.com/AmariahAK/atlarix-releases/security/advisories/new) if you prefer. Either channel reaches us; the email is the one [atlarix.dev/security](https://atlarix.dev/security) advertises, and the two used to disagree.

Please do not open a regular public issue — the information could be used against Atlarix users before a fix ships.
