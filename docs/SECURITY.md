# Security Policy

## Supported Versions

We provide security fixes for the latest version only. Most desktop installs update themselves
(the Microsoft Store build updates through the Store; a Linux deb/rpm or a Mac build outside
/Applications is notified instead), and the Chrome extension updates through the Chrome Web
Store. The Atlarix Core service and Atlarix Reviewer are hosted, so a fix reaches
everyone when it deploys.

## Reporting a Vulnerability

Email **security@atlarix.dev**. We acknowledge within 48 hours. This is the address
[atlarix.dev/security](https://atlarix.dev/security) advertises.

You can also report privately through GitHub's
[report-a-vulnerability form](https://github.com/AmariahAK/atlarix-releases/security/advisories/new).
Either channel reaches us.

Please do not open a regular public issue. The information could be used against Atlarix users
before a fix ships.
