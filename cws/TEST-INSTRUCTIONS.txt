WHAT TO TRY (about two minutes)
1. Open any article, for example https://en.wikipedia.org/wiki/Antikythera_mechanism
2. In the panel, ask: "What is this and what do researchers still disagree about?"
3. Atlarix will ask for permission to read that one site. Chrome's own
   permission prompt appears — click Allow. Access is requested per site, at the
   moment it is needed; the extension holds no host access at install.
4. It reads the page and answers. The activity card above the answer expands to
   show exactly what it did.

OPTIONAL, IF YOU WANT TO SEE THE REST
- Attach a file with the + button and ask a question about it. Text, images,
  PDFs and Office documents are read on the device; nothing is uploaded.
- Ask "make me a relic that converts currencies". This generates a small
  self-contained HTML document which opens in its own tab.
- Ask "make me a CSV of the ten largest countries by area". Atlarix writes the
  file and offers it as a Download card in the conversation. The file is built
  on the device and is never uploaded.
- Those two features are the remote code declared on the Privacy tab. Both run
  only inside pages declared under the manifest's "sandbox" key — opaque
  origin, no extension APIs, connect-src 'none', so neither has any network
  access. The second runs its code in a worker created inside that sandboxed
  page, which inherits the same origin and the same policy, and which is
  terminated if it runs longer than 15 seconds.
- Every site the agent has been granted can be reviewed and revoked from the
  panel menu, or at atlarix.dev/account.

NOTES FOR REVIEW
- The "debugger" permission is used only to dispatch trusted keyboard and mouse
  input to a granted tab, because it is the only API in Chrome that produces
  events with isTrusted = true. Without it, pressing Enter to submit a form and
  CSS :hover menus do nothing. It attaches to one granted tab for the duration
  of an action and detaches immediately. It is never used to read network
  traffic, evaluate script, or observe an ungranted tab.
- Atlarix fills forms but never submits them. Anything that sends, buys, posts
  or deletes stops and asks the user first.
