WHAT TO TRY (about two minutes)
1. Open any article, for example https://en.wikipedia.org/wiki/Antikythera_mechanism
2. In the panel, ask: "What is this and what do researchers still disagree about?"
3. The first time Atlarix works on a site, the panel asks you to allow it —
   click Allow. That per-site list is visible and revocable from the panel menu.
4. It reads the page and answers. The activity card above the answer expands to
   show exactly what it did.

OPTIONAL, IF YOU WANT TO SEE THE REST
- Attach a file with the + button and ask a question about it. Text, images,
  PDFs and Office documents are parsed on the device and kept there; the parts
  the question needs are sent to the model with it.
- Ask "open example.com in a new tab and take a screenshot of it". Atlarix
  opens its own tab (in the "Atlarix" tab group) and shows what it saw.
- Ask "make me a relic that converts currencies". This generates a small
  self-contained HTML document which opens in its own tab.
- Ask "make me a CSV of the ten largest countries by area". Atlarix writes the
  file and offers it as a Download card in the conversation. The file is built
  on the device and is never uploaded.
- Those two features are the remote code declared on the Privacy tab. Both run
  only inside pages declared under the manifest's "sandbox" key — opaque
  origin, no extension APIs, connect-src 'none', so neither has any network
  access. The second runs its code in a worker created inside that sandboxed
  page, which inherits the same origin and the same policy, and which is
  terminated if it runs longer than 15 seconds.
- Every site the agent has been granted can be reviewed and revoked from the
  panel menu, or at atlarix.dev/account.

NOTES FOR REVIEW
- The "debugger" permission is used only on tabs Atlarix itself opened (its
  "Atlarix" tab group) and refuses any tab you opened. There it sends trusted
  keyboard and mouse input (the only API giving isTrusted events — without it
  Enter does not submit and :hover menus do not open), records that tab's
  console and network activity so the agent can explain a failing page, and
  takes screenshots of it. Chrome's "started debugging" banner shows on those
  tabs while they are open. It never inspects memory, sets breakpoints or
  evaluates script.
- Atlarix fills a form and stops; it submits only when the user asked it to.
  Passwords, payments, downloads and anything destructive always stop and ask,
  whatever the site grant.
- Host access is requested at install (http and https). It is required for
  the paired Atlarix desktop app, whose requests run without a per-site prompt
  in the browser; in the side panel each new site is still asked first. Users
  can narrow it per site from chrome://extensions.
