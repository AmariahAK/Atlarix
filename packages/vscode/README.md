# Atlarix for VS Code

Atlarix in your editor: VS Code, Cursor, Kiro, Windsurf and other editors built on VS Code.

- **Any model.** Atlarix Auto, Atlarix Core, or your own key for any provider you've connected in Atlarix.
- **Every mode.** Build, Explore, Plan, Debug and Review, switched from the message box.
- **Changes you approve.** Edits open in the editor's own diff before anything is written; every command waits for your yes in Build mode.
- **Plans you can build.** Plan mode writes a plan; "Build it" carries it out.
- **Your Chrome.** With the Atlarix Chrome extension connected, Atlarix can read and drive your browser.
- **Your other sessions.** Atlarix sessions in the app, the terminal, Chrome and other editors can message each other.
- **Your selection.** Select code and press ⌘⌥L (Ctrl+Alt+L), or type @ to add a file.
- **Back where you were.** A one-line recap when you return after a few minutes away (switch it off in the ⋯ menu).

Sign in with your Atlarix account the first time. Your chats, keys and settings are the same as in the Atlarix app and CLI.

Zed and JetBrains IDEs: use Atlarix through the Agent Client Protocol instead — see [atlarix.dev/docs/guides/editors](https://atlarix.dev/docs/guides/editors).
